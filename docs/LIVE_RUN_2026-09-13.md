## 1. 结论摘要

本队 Agent 成功使用账户绑定身份加入正式 Arena 2 房间，发布产品介绍及销售信息，并保持 SharedNet listener 长轮询在线。公网 Seller 服务、Catalog、Agent Card 与 Dashboard 在比赛期间可访问。官方 SharedNet 账本最后一次成功查询确认累计收入 `received=36` credits。

本次运行证明了以下链路：

1. 正式账户登录与 competition seat 加入；
2. 房间消息发布、读取和持续监听；
3. 公网产品发现入口可访问；
4. 其他 Agent 的付费购买进入官方 credits ledger；
5. Agent 在用户设定的预算约束下保持监听和销售宣传。

本次运行**没有保存足够证据证明所有收款均已完成对应报告交付**。已确认 credits settlement，但买家输入、订单、生成的 artifact 和交付回执没有形成完整的本地证据包，因此不能把 36 credits 收入写成 6 份已交付报告。

### 2.1 比赛轮次要求与实际执行边界

首轮房间要求 Agent 介绍产品、给出产品链接和 MCP/CLI 接入方法，逐一评论其他产品，并持续参与问答、质疑和辩护。第二轮要求再次说明免费/付费能力与价格、主动销售，同时评估并购买其他产品；房间提示要求在一小时内花完 100 credits。

实际运行始终服从用户设定的预算约束，没有把房间中的通用消费提示视为无条件授权。现有证据可以确认我方产品介绍和后续销售消息，不足以逐条证明已经评论了房间内每一个其他产品，因此本记录不宣称完全满足该项覆盖要求。

### 3.2 SharedNet listener

Listener 使用账户绑定的正式 seat 凭据启动，并将运行身份与 inbox/cursor 保存到 ModelScope 工作区的私有持久路径。运行日志持续出现对正式 Room `wait` 接口的 `HTTP/1.1 200 OK`，最后一次人工观察时已推进到至少 sequence 808。

Listener 与 Seller API 是两个独立进程：

- Seller API 负责公开产品、报价、订单和报告交付；
- Listener 负责房间发现、产品问答、宣传和接收请求。

本次运行中两个进程均曾同时在线。没有把 Dashboard 可访问误记成房间 Agent 在线。

## 7. LLM 与降级结果

### 7.1 现场故障

初始自检发现 ModelScope 进程中 `MODEL_API_KEY` 未设置。随后 OpenRouter 调用出现连接超时和 402：请求上限为 4,000 tokens，但账户余额只够约 3,187 tokens。GLM 与 DeepSeek 候选均未返回有效结构化结果。

### 7.2 运行策略

为避免模型故障让 Agent 整体停机，系统保持以下边界：

- 预算、付款、定价、Schema、证据权重、风险规则和幂等由确定性代码控制；
- 模型只生成受证据约束的自然语言 critique/回答；
- 主模型失败后尝试备用模型；
- 两个模型均失败时记录 fallback，并使用确定性内容继续运行；
- 当前仓库默认 `max_tokens=800`，避免再次出现 4,000-token 预算错误。

现场曾切换到可配置的 OpenAI-compatible 低成本供应商方案，计划使用 GLM 为主、DeepSeek 为备用。但本地未保存一份带 provider、model、响应 Schema 和成功时间戳的正式模型调用回执，因此本记录**不宣称正式 Arena 回复由 LLM 成功生成**。可以确认的是：房间 listener 和确定性销售信息在模型结果不可靠时仍能运行。

## 8. 运行期间遇到的故障

### 8.1 SharedNet 间歇性不可用

`say`、`balance`、`ledger` 等操作曾返回 `service_unavailable`。GET/wait 长轮询在同一阶段仍多次返回 200，表现为写操作和部分账本读取间歇失败，而不是整个 listener 永久掉线。

处置：

- 不把一次失败当成最终状态；
- 不因 room receipt 缺失重复执行有副作用的操作；
- 使用稳定幂等键重试消息；
- 在 API 恢复后确认 sequence 773 和 806 已正式发布；
- 使用 balance/ledger 区分结算状态与回执状态。

### 8.2 模型余额与网络问题

OpenRouter 出现 402 和 ConnectTimeout，且最初环境变量未注入。处置为缩短输出、允许供应商切换、保留主备模型，并确保确定性降级不会触发付款或事实判断。

### 8.3 临时计算环境期限

ModelScope DSW 页面显示剩余运行时间，意味着公开 URL 和 listener 可能随实例到期停止。比赛运行完成后，不再将该 URL 视为长期 SLA 入口。

### 8.4 首次房间与身份接入

早期 QA seat 与正式 Arena seat 不同。正式运行使用 `i_7HNXrFF445`，没有复用 QA seat `i_E0nD7EzS5k`。这验证了 QA 身份只能作为联调证据，不能代替正式比赛身份。

## 9. 与本地 Harness 证据的关系

正式运行之前，Seller Harness 已完成 7,755.5 秒持续测试：16 并发、32,272 笔唯一交易全部 `delivered`、未完成交易 0、SQLite integrity `ok`。该测试证明本地订单幂等、冲突拒绝、来源降级和交付路径，但不证明 SharedNet 正式房间或 credits 结算。
