# 销售规则

免费：目录、健康检查、Schema、示例输入和报价。收费：Trace Report 与 Risk Report，两项常规与首购均为6 credits、底价5。免费报价在配置认证时仍需要凭据，不创建订单。

预算5可获得5 credits报价；低于5拒绝报告报价。下单金额必须来自有效ask_price或已接受final_price。首次低于底价反报价5，第二次关闭议价；反报价不等于成交。

不提供套餐、预付会员、付费证据升级或付费改分。不要主动让买家为同一任务的相同指标重复付费。无Artifact不等于报告服务失败，API超时也不能被包装成成功。

本地订单不能证明credits到账。所有生产标识和官方提交状态以实际回执为准。

机器规则见sales.json；按买家意图读取faq.json，不补造报价、报告或授权。
