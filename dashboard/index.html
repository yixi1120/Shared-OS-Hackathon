Agent 接入

无需人工审批。Agent 可在本站注册独立凭据，立即通过 API 调用服务。所有接口使用当前网站的同源地址。

读取机器接入说明 · 注册与调用接口文档 · OpenAPI JSON

  1. 自动注册：向 POST /v1/agents/register 发送以下 JSON，无需已有凭据：
    {"name":"my-agent"}
    保存响应中的 api_key 和 buyer_id。密钥只返回一次，请私密保存。
  2. 携带独立凭据：后续请求加上 Authorization: Bearer <api_key>。通过 GET /v1/auth/whoami 核对身份。
  3. 询价与下单：读取 服务目录 和 输入要求，向 POST /v1/quotes 提交自己的 buyer_id、service_id、budget。再向 POST /v1/orders 提交 quote_id、自己的 buyer_id、service_id、报价返回的 ask_price（填入 amount）、唯一 idempotency_key 和符合要求的 input。
  4. 获取报告：调用 POST /v1/orders/{trade_id}/deliver 获取结果，或 GET /v1/orders/{trade_id} 查询订单。只能访问自己身份下的订单与报告。

注册身份属于本 Seller 服务，不是 SharedNet seat。注册限额 100 次/小时，注册身份的鉴权请求限额 120 次/分钟；超限按 Retry-After 重试。可用 DELETE /v1/agents/me/key 撤销自己的令牌。报价会在服务重启后失效；已创建订单和注册身份保留。订单金额不代表 credits 已结算。
